# 🛍️ Telegram-бот для автоматической продажи цифровых товаров с админ-панелью

Профессиональное и готовое решение для автоматизации онлайн-бизнеса в Telegram. Бот предназначен для мгновенной продажи любых цифровых товаров (ключей активации программ, лицензий, аккаунтов, промокодов, ссылок доступа или файлов) без участия продавца.

---

## 🔥 Ключевые возможности проекта

### 🧑‍коммерческая Часть (Для клиентов):
* **Интерактивное меню:** Удобный и интуитивно понятный каталог товаров на Inline-кнопках.
* **Автоматический прием оплаты:** Интеграция с официальной платежной системой Telegram Payments (подключение ЮKassa, Сбербанк, Qiwi и др.).
* **Мгновенная выдача товара:** Сразу после фиксации успешной оплаты бот автоматически забирает уникальный ключ/файл из базы данных и отправляет его клиенту.
* **Раздел поддержки:** Быстрый переход на диалог с администратором или FAQ.

### ⚙️ Админ-панель (Для владельца бизнеса):
* **Защищенный доступ:** Вход в панель управления доступен строго по Telegram ID администратора.
* **Управление товарами:** Добавление новых позиций, загрузка партий ключей и отслеживание остатков в реальном времени через интерфейс бота.
* **Бизнес-аналитика (Статистика):** Быстрый просмотр количества уникальных пользователей, числа успешных продаж и чистой выручки за день/неделю.

## 🛠️ Технологический стек проекта

* **Язык разработки:** Python 3.12+
* **Фреймворк для Telegram API:** `aiogram 3.x` (современная асинхронная библиотека с поддержкой актуальных методов API)
* **Работа с данными:** Асинхронная архитектура эмуляции СУБД (готовая к быстрому масштабированию на SQLite / PostgreSQL)
* **Платежный шлюз:** Telegram Payments API (Invoice / PreCheckoutQuery)

## 🚀 Инструкция по быстрому запуску

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python версии 3.12 или выше. Склонируйте репозиторий и установите необходимые зависимости:

```bash
pip install aiogram
```

### 2. Конфигурация и запуск
Откройте файл `telegram_shop_bot.py` и заполните следующие переменные:
* `BOT_TOKEN` — токен вашего бота, полученный у [@BotFather](https://t.me).
* `PAYMENTS_TOKEN` — токен платежного шлюза (например, ЮKassa), привязанный к вашему боту в BotFather.
* `ADMIN_ID` — ваш числовой ID в Telegram (можно узнать у специальных ботов, например, [@userinfobot](https://t.me)).

Запустите скрипт:
```bash
python telegram_shop_bot.py
```
